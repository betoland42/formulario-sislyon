# Formulario de soporte técnico SISLYON

## Sitio desplegado

[Ver formulario en GitHub Pages](https://betoland42.github.io/formulario-sislyon/)

Formulario web desarrollado para registrar solicitudes de soporte técnico relacionadas con equipos de cómputo, impresoras, instalación de software, redes y actualizaciones de hardware.

## Objetivo

Crear una página web con un formulario validado mediante HTML5 y JavaScript, utilizando manipulación del DOM y eventos para brindar retroalimentación al usuario.

## Funcionalidades

- Registro del nombre del cliente.
- Validación de correo electrónico.
- Validación de teléfono de 10 dígitos.
- Selección del servicio requerido.
- Selección del tipo de equipo.
- Descripción del problema.
- Aceptación de términos y condiciones.
- Mensajes de error para campos incompletos.
- Mensaje personalizado cuando la solicitud es válida.
- Limpieza automática del formulario después del envío.
- Diseño adaptable para computadoras y dispositivos móviles.

## Tecnologías utilizadas

- HTML5 semántico
- CSS3
- Bootstrap 5
- JavaScript
- DOM
- Eventos de JavaScript
- Git y GitHub
